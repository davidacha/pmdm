Agenda-David-Acha

Proyecto de Agenda Personal / Gestor de Contactos y Eventos

Descripción

“Agenda-David-Acha” es una aplicación móvil/web (según el alcance) que permite gestionar contactos, eventos y recordatorios de manera sencilla e intuitiva. El objetivo es ofrecer una herramienta organizada para usuarios que desean centralizar sus compromisos, tareas y relaciones en un solo lugar.

Este proyecto fue creado como parte de la asignatura Programación Multimedia y Dispositivos Móviles.

Características principales

- Gestión de eventos/recordatorios.

- Interface clara y fácil de usar.

- Persistencia de datos local (o remota, si se añade backend).


Motivación / Valor añadido

- Resolver la necesidad básica de muchas personas de tener toda su información personal organizada en un único lugar.

- Potencial de escalabilidad: se puede convertir en una aplicación real, conectada a servicios en la nube, con funciones colaborativas, etc.

- Demostrar competencias técnicas en desarrollo móvil/web, arquitectura, buenas prácticas y usabilidad.
